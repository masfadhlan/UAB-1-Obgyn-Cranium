# Latihan UAB 1 Obgyn — Cranium

Latihan interaktif 154 soal UAB 1 Obgyn (123 compile + 31 soal tambahan) lengkap dengan kunci dan pembahasan berbasis slide kuliah.

## Cara publikasi di GitHub Pages
1. Upload dalam **2 kali unggah** (batas web GitHub 100 file per unggah):
   - **Unggahan 1:** ekstrak `Bagian1.zip`, lalu drag-and-drop `index.html`, `README.md`, dan folder `slides-1/` (61 file) ke *Add file → Upload files* → Commit.
   - **Unggahan 2:** ekstrak `Bagian2.zip`, lalu drag-and-drop folder `slides-2/` (58 file) → Commit.
   - Kedua folder harus berada di root, sejajar dengan `index.html`.
2. Buka **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / folder `/ (root)` → Save.
3. Setelah 1–2 menit, situs tersedia di `https://<username>.github.io/<nama-repo>/`.

## Fitur
- Mode **Latihan** (kunci dan pembahasan langsung muncul) dan **Ujian** (nilai keluar setelah selesai).
- Filter set soal, topik, belum dijawab, dan yang salah. Bisa acak urutan.
- Setiap pembahasan menampilkan gambar halaman slide kuliah yang menjadi dasar jawaban. Klik gambar untuk memperbesar.
- Progres tersimpan otomatis di browser.
- Pintasan keyboard: A–E / 1–5 untuk memilih, ← → untuk navigasi.
